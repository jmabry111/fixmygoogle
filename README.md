# Mabry Technologies — Google Presence Optimization

Service page for Mabry Technologies' Google Presence Optimization offering: Google Business Profile optimization, local SEO, website content, and review support for small businesses.

Live site: https://mymabry.com

## Contents

- `index.html` — the complete site as a single self-contained file (styles, fonts, and scripts included).

## Hosting

Hosted on GitHub Pages.

1. Push `index.html` to the repository's default branch.
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", and select the branch and `/ (root)` folder.
3. For a custom domain, enter it under **Custom domain** and add the DNS records GitHub provides.

## Updating

The page is generated from a design source file. Make changes there and re-export `index.html` rather than editing the exported file by hand.
